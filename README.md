# Mapas de obra · exemplos

Dois mapas de obra de demonstração da We Garden, com obras fictícias: jardins de um hotel e cobertura verde de um edifício de escritórios. São abertos a partir da página https://wegarden.pt/mapas-de-obra/.

- `exemplo-jardim-hotel.html`
- `exemplo-cobertura-verde.html`
- `fotos/`: fotografias das espécies, do Flora-On (CC BY-NC 4.0)
- `img/`: imagens da página
- `wp/pagina.html`: conteúdo do bloco «HTML personalizado» da página no WordPress (no site, as imagens vêm da biblioteca de multimédia)
